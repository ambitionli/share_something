## E2E 验收测试 7 大场景

### 场景一：管理员上架商品 (4/4)
- 管理员登录获取 token
- 创建商品 HTTP 201
- 上架后买家端搜索可见
- 下架后买家端搜索不可见 + 重新上架

### 场景二：买家注册与登录 (6/6)
- 手机号+密码注册 HTTP 201
- 退出后重新登录
- 短信验证码发送 + 验证登录（自动注册新用户）
- 微信 OAuth 登录（新用户返回 needs_bindphone）
- 未登录下单被拒 HTTP 401

### 场景三：买家浏览与购买 (6/6)
- 商品列表展示（>0 件上架商品）
- 关键字搜索功能
- 商品详情 HTTP 200
- 创建订单 HTTP 201，状态 pending
- 库存不足下单被拒 HTTP 400

### 场景四：支付流程 (4/4)
- 模拟支付 pending -> paid，生成支付 ID
- 重复支付被拒（幂等性）HTTP 400
- 取消订单后库存恢复（精确验证数值一致）

### 场景五：卖家发货 (3/3)
- 管理员查看待发货订单
- 填写快递信息发货 paid -> shipped
- 快递单号正确记录

### 场景六：买家确认收货 (5/5)
- 查看物流信息存在
- 确认收货 shipped -> completed
- 历史订单列表有记录
- 收货人信息正确
- 订单金额计算正确

### 场景七：异常场景 (7/7)
- 已完成订单不能取消 HTTP 400
- 已完成订单不能再发货 HTTP 400
- 其他买家不能查看他人订单 HTTP 403
- 买家不能创建商品 HTTP 403
- 买家不能查看全部订单 HTTP 403
- 无效 token 被拒 HTTP 401
- 响应包含 X-Request-ID
