# 微信小程序外卖演示项目（邻里即达）

> 最后更新：2026-04-16 23:59

## 概述

仓库新增独立目录 `wechat-miniapp/`，实现一个基于 **微信小程序原生（WXML + WXSS + JS）+ 云函数骨架** 的本地生活配送演示项目，覆盖：

- 用户登录（手机号 / 微信授权模拟）
- 首页商家列表、分类、搜索、Banner
- 商家页、购物车、结算、模拟支付
- 订单流转：待支付 -> 待接单 -> 已接单 -> 配送中 -> 已完成
- 评价、退款、个人中心
- 商家入驻、商品管理、订单管理、经营统计

默认以本地 mock 数据运行，可直接导入微信开发者工具查看页面和交互；同时提供云函数目录与数据库结构说明，便于迁移到云开发。

## 核心实现

### 1. 统一业务引擎

`shared/order-engine.js` 承载订单、购物车、退款、评价、商家商品管理等核心逻辑，并被以下两层复用：

- 小程序本地 mock 服务 `services/api.js`
- 云函数 `cloudfunctions/*`

这样页面层与后端逻辑保持一致，避免前后端状态机分叉。

### 2. 订单与退款规则

- 下单必须带 `submitToken`，保障幂等
- 购物车数量不能为负数
- 商品库存不足时拒绝加购 / 下单
- 商品价格必须大于 0，库存不能为负数
- 商家拒单或退款通过时，根据订单阶段自动恢复库存
- 已评价订单禁止再次评价；已评价完成单不允许再申请退款

### 3. 商家侧能力

- 商家入驻
- 商品新增 / 编辑 / 上下架
- 商家接单 / 拒单 / 标记配送
- 查看总订单、处理中订单、完成单、销售额、退款额

## 自动验收

执行：

```bash
cd wechat-miniapp
npm test
```

通过 5 项核心验收：

1. 完整下单链路
2. 退款链路
3. 幂等下单
4. 库存保护
5. 商家商品编辑与上下架对买家搜索结果的影响

## 备注

- 页面默认使用本地 mock 数据，因此无需真实云环境即可体验。
- 若切换到真实云开发，可保留页面层，替换 `services/api.js` 为 `wx.cloud.callFunction` 版本。
- 本次新增内容为独立小程序工程，不影响仓库原有 backend / mobile / admin-web 项目。
