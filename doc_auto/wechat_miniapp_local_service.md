# 微信小程序本地生活服务 - 完成记录

> 最后更新：2026-04-16 00:00 UTC

## 新增目录

- `wechat-miniapp/`：微信小程序原生工程
- `wechat-miniapp/pages/`：用户端与商家端页面
- `wechat-miniapp/shared/core.js`：订单、库存、退款、评价共享业务逻辑
- `wechat-miniapp/cloudfunctions/`：登录、下单、支付回调、退款、评价、统计云函数
- `wechat-miniapp/tests/core.test.js`：Node 内置测试驱动的验收脚本

## 已实现功能

### 用户端
- 手机号登录 / 微信授权登录（演示模式）
- 首页 banner、分类筛选、搜索、商家列表
- 商家详情页、商品列表、评分、销量、配送费、起送价
- 购物车加减、单商家结算约束、备注
- 下单、地址选择、优惠券、模拟支付
- 订单列表：待支付、待接单、配送中、已完成、已退款、已取消
- 退款申请、完成确认、评价（星级 / 文本 / 图片链接）
- 个人中心：地址管理、优惠券、余额、客服、设置

### 商家端
- 商家入驻（信息 + 资质链接）
- 商品管理（新增、编辑、上下架、库存、价格）
- 订单管理（接单、拒单、标记配送、处理退款）
- 数据概览（订单、完成数、收入、退款、有效商品数）

### 云开发
- `login`：手机号 / 微信演示登录
- `placeOrder`：下单
- `payCallback`：模拟支付回调
- `refund`：退款申请 / 退款处理
- `review`：订单评价
- `stats`：商家概览统计

## 验收与验证

- 使用 `node --test tests/*.test.js` 执行自动化验收
- 重点覆盖：
  - 完整链路：加购 -> 结算 -> 支付 -> 接单 -> 配送 -> 完成 -> 评价
  - 退款链路：申请退款 -> 商家处理退款
  - 风险校验：负库存、重复支付、价格异常、单商家结算限制
  - 商家能力：入驻、商品创建、上下架、订单处理、统计

## 运行说明

- 微信开发者工具直接导入 `wechat-miniapp/`
- 默认使用本地 `wx.setStorageSync` 演示数据运行
- 可按 `README.md` 将 `shared/core.js` 替换为真实云数据库实现
