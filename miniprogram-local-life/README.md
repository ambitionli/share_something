# 邻刻达 · 本地生活小程序（微信云开发）

面向「本地生活服务 + 商家入驻 + 用户下单 + 配送 + 评价 + 退款」的演示级完整项目，技术栈为 **微信小程序原生 + 云开发（云数据库 + 云函数 + 云存储）**。

## 目录结构

- `miniprogram/`：小程序前端（页面、工具库）
- `cloudfunctions/lnk_api/`：统一云函数，通过 `action` 分发业务
- `tests/`：Node 单元测试（金额与库存校验逻辑）
- `DATABASE.md`：云数据库集合与字段说明
- `ACCEPTANCE_REPORT.md`：自检验收清单

## 部署步骤

1. **安装开发者工具**  
   使用微信开发者工具，导入本项目根目录（与 `project.config.json` 同级）。

2. **开通云开发**  
   在工具中创建云环境，记下 **环境 ID**。  
   在 `miniprogram/app.js` 的 `wx.cloud.init({ env: '你的环境ID' })` 中填入（或依赖工具「云开发」面板关联环境）。

3. **创建云数据库集合**  
   按 `DATABASE.md` 在控制台新建集合并配置权限（开发期可设为「所有用户可读，仅创建者可写」等，上线前务必收紧）。

4. **上传并部署云函数**  
   右键 `cloudfunctions/lnk_api` → 上传并部署：云端安装依赖。

5. **初始化演示数据（可选）**  
   - 首页加载时会尝试调用 `seed_demo`；或  
   - 在「我的」页点击「初始化演示数据」。

6. **运行**  
   编译预览。真机调试需使用已配置合法域名的 AppID（测试号可使用云开发基础能力）。

## 功能说明（摘要）

**用户端**：手机号登录、微信头像昵称同步、首页分类/搜索/Banner、商家与商品、购物车与备注、地址管理、模拟支付下单、订单状态（待支付/待接单/配送中/已完成/退款相关）、评价（星级+文字+云存储图片）、个人中心（余额/优惠券占位、客服入口、设置）。

**商家端**：入驻（含资质图上传云存储）、商品上下架与改价改库存、接单/拒单（退回库存）、配送完成、退款审批（同意则退回库存）。

**安全与逻辑**：下单与支付在云函数侧校验起送价、金额重算、库存；合并重复行；支付在事务内扣减库存；拒单/同意退款回滚库存。

## 测试

在项目根目录执行：

```bash
npm test
```

## 打包为 zip（可选）

在仓库根目录执行：

```bash
zip -r miniprogram-local-life.zip miniprogram-local-life
```

（`miniprogram-local-life.zip` 已加入根目录 `.gitignore`，便于本地分发而不进版本库。）

## 说明

- **支付**为 `order_pay` 模拟支付，非真实微信支付；接入生产需替换为微信支付统一下单 + 支付回调云函数。
- **优惠券**前端为演示列表，与订单联动可在云函数扩展。
- **客服**页使用 `open-type="contact"`，需在小程序后台配置客服。
