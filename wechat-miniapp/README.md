# Neolife Local 微信小程序

一个原生微信小程序示例项目，覆盖本地生活服务场景：商家入驻、用户下单、配送、评价、退款、商家经营管理。

## 功能概览

### 用户端
- 手机号登录 / 微信授权登录（演示模式）
- 首页商家列表、分类筛选、搜索、Banner
- 商家页商品浏览、加减购物车、起送价和配送费展示
- 购物车与结算页
- 模拟支付、订单状态流转
- 订单列表、退款申请、评价
- 个人中心、地址管理、优惠券 / 余额 / 客服信息展示

### 商家端
- 商家入驻
- 商品管理：新增、上下架、改价、改库存
- 订单管理：接单、拒单、标记配送、处理退款
- 数据概览：订单、收入、退款统计

### 云开发交付
- 云函数：`login`、`placeOrder`、`paymentNotify`、`refundOrder`、`submitReview`、`stats`
- 云数据库结构说明：`database/schema.md`

## 目录结构

```text
wechat-miniapp/
├── app.js / app.json / app.wxss
├── pages/                  # 小程序页面
├── services/appService.js  # 本地业务引擎
├── store/                  # 演示数据与本地持久化
├── utils/                  # 金额和校验工具
├── cloudfunctions/         # 云函数示例
├── database/schema.md      # 数据库结构说明
├── docs/acceptance-report.md
└── scripts/*.test.js       # Node 自动验收脚本
```

## 本地运行

1. 打开微信开发者工具。
2. 选择 `wechat-miniapp` 目录导入项目。
3. 当前 `project.config.json` 使用 `touristappid`，仅用于本地演示。若接入真实云开发，请替换成自己的小程序 AppID。
4. 直接点击编译即可运行，默认使用本地 Mock 数据，不依赖额外后端。

## 云开发部署

1. 在微信开发者工具中开通云开发环境。
2. 按 `database/schema.md` 创建集合。
3. 分别进入 `cloudfunctions/*` 目录，执行 `npm install` 安装 `wx-server-sdk`。
4. 上传并部署全部云函数。
5. 如需切换到真实云函数模式，可在 `services/appService.js` 外包一层云调用适配器；当前交付重点是确保项目即刻可运行。

## 自动验收

在项目目录执行：

```bash
npm test
```

脚本会自动验证：
- 用户主链路：登录 -> 加购 -> 下单 -> 支付 -> 接单 -> 配送 -> 完成 -> 评价
- 退款链路：退款申请 -> 商家处理
- 异常防护：重复下单、库存不足、非法状态
- 项目结构：页面与云函数文件存在
